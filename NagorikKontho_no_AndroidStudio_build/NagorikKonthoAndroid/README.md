# নাগরিককণ্ঠ — Android Studio Project

এই প্রজেক্টে তোমার বর্তমান `nagorik_extreme_final.html` এবং `logo.png` সরাসরি Android অ্যাপের assets হিসেবে bundled করা হয়েছে। অ্যাপটি WebView দিয়ে HTML চালাবে এবং image upload-এর জন্য Android file picker খুলবে।

## চালানোর নিয়ম

1. পুরো `NagorikKonthoAndroid` folder Android Studio-তে খুলবে।
2. Gradle sync শেষ হতে দেবে।
3. ফোন বা emulator connect করবে।
4. **Run** চাপবে।
5. APK বানাতে **Build → Build APK(s)** চাপবে।

## গুরুত্বপূর্ণ

HTML-এর Firebase, Leaflet, Chart.js, Font Awesome এবং Google Fonts CDN resource আছে, তাই app-এর জন্য Internet permission রাখা হয়েছে।

Launcher icon হিসেবেও তোমার `logo.png` রাখা হয়েছে।
